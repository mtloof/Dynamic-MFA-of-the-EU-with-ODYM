# Dynamic MFA and Circularity Analysis of the EU using ODYM in python

Dynamic MFA across 4 broad material categories and 3 specific materials across the EU for both historic and projected circularity.

Dynamic MFA was conducted using ODYM package.

All charts are summarized in a final dashboard which may be opened in a browser for better viewing - just click the link in the final code cell.

All data must be unzipped and added to the same folder as the jupyter notebooks before running the code.
